Building Fluid, Responsive Web Layouts

I'm Shivam, a Frontend Developer at DecodeLabs. This page adapts smoothly from a small phone screen to a large desktop monitor using mobile-first CSS, media queries, and fluid units — no fixed dimensions.

About This Project

Project 2 of the DecodeLabs Industrial Training Kit is my adaptability phase. Instead of designing for one fixed screen, I designed for content: the layout below reflows using CSS Grid for macro structure and Flexbox for component alignment, with breakpoints placed exactly where the design starts to break, not at arbitrary device widths.

Core Responsive Techniques

Media Queries

Breakpoints at 480px, 768px, and 1024px reshape the layout as the viewport grows, built mobile-first with min-width queries.

Fluid Typography

Headings use clamp() so font size scales smoothly with the viewport instead of jumping between fixed steps.

Responsive Navigation

A hamburger menu (native Popover API, no JavaScript) appears on small screens; a full inline nav appears on larger ones.

Accessible Touch Targets

Every interactive element keeps a minimum 44x44px tap area, and pinch-zoom is never disabled.
